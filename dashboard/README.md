# Dashboard Scaffold

React + TypeScript single-page app providing the global monitoring view.

## Quick Start

```bash
npm create vite@latest dashboard -- --template react-ts
cd dashboard
npm install
npm run dev
```

The scaffold here assumes Vite tooling; adjust commands if using a different setup. Ensure the control plane API is reachable at `http://localhost:8000/api/v1` during development.
